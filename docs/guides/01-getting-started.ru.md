# Начало работы

[English](01-getting-started.md) · [Oʻzbekcha](01-getting-started.uz.md) · **Русский**

## 1. Подготовка проекта

```bash
# Новый проект из шаблона — выполняется один раз
./scripts/init-project.sh

# Присоединяетесь к существующему проекту — начните отсюда
make setup    # создаёт .env и ставит зависимости
make dev      # поднимает postgres и остальные локальные сервисы
```

Секретные значения в `.env` заполните вручную — этот файл никогда не попадает в
репозиторий.

Нужна очередь? `make dev-queue` поднимет ещё и redis.

## 3. Проверка

```bash
make doctor   # соответствие env, битые ссылки, отсутствующие инструменты
make lint
make test
```

Проверьте вручную:

- Приложение открывается локально.
- Документация API работает (`/docs` или `docs/api/openapi.yaml`).
- Тесты проходят.

То, что `make lint` и `make test` ничего не делают, — нормально, пока шаблон
пуст: они сообщают, сколько каталогов пропущено.

## 4. Выбор языка

Вывод скриптов определяется по `STARTER_LANG`, иначе по системной локали, с
откатом на английский:

```bash
STARTER_LANG=ru make doctor
```
